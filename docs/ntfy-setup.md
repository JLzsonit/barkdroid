# 短信转发到安卓 —— 3 步接入指南

> 通道已从极光推送换成 **ntfy 直连**：不依赖任何厂商推送、不需要账号、不需要服务器，只走标准 HTTPS。
> App 打开即为「在线」，无需等待设备 ID。

---

## 第一步：装 App

1. 把 `barkdroid-v2.apk` 传到安卓手机，点击安装（提示"未知来源"就允许）。
   - 已经装过旧版的**可以直接覆盖安装**，不用卸载（签名和包名都没变）。
2. 打开 App → 允许通知权限。
3. 首页顶部应显示 **● 在线接收中**。
4. 在「你的推送地址」卡片点 **复制推送地址**，形如：

```
https://ntfy.sh/sms-3f9a1c7d02
```

> 这个地址就是你的"专属收件箱"，频道名是随机的，别人猜不到。在「设置 → 接收配置」里可以换。

---

## 第二步：iPhone 快捷指令

**你原来那条 Bark 转发不用动，新建一个独立的快捷指令即可。**

### 做法 A：最简单（正文即短信内容）

1. 快捷指令 App → 右上角 **+** 新建，命名「短信→安卓」
2. 添加动作 **获取 URL 内容**
3. 地址：粘贴刚才复制的推送地址
4. 点动作里的小箭头展开：
   - **方法** → `POST`
   - **请求体** → `文本`
   - 文本框里填短信内容，例如：`发件人：（发件人变量）　内容：（短信内容变量）`
5. 完成

### 做法 B：通知标题显示发件人（推荐，中文不乱码）

1. 同上新建，添加 **获取 URL 内容**
2. 地址：`https://ntfy.sh/`（只有服务器根地址，**不带频道名**）
3. 展开后：
   - **方法** → `POST`
   - **请求头** → 添加一条：`Content-Type` = `application/json`
   - **请求体** → `JSON`，填三个字段：

| 字段 | 值 |
|---|---|
| `topic` | 你的频道名，例如 `sms-3f9a1c7d02` |
| `title` | 发件人变量 |
| `message` | 短信内容变量 |

---

## 第三步：自动化（自动触发）

快捷指令 App → 底部 **自动化** → **+** → **信息**：

- 条件：**信息包含 信息**（即收到任何短信）
- 建议加一个「发件人不是 短号/服务号」的过滤，减少垃圾通知
- 下一步 → 选择刚建的「短信→安卓」→ 关闭「运行前询问」→ 完成

---

## 小米 / 华为 / OPPO 必做（否则息屏收不到）

App 内「必要权限」卡片可以直接跳转，逐项设置：

1. **通知权限**：允许
2. **省电策略** → 选 **无限制**（默认"智能省电"会掐掉后台联网）
3. **自启动** → 允许
4. **后台弹出界面** → 允许（部分机型需要）
5. 最近任务里把 App **上滑锁定**（加锁图标）

装完在「设置 → 接收自检」点一次 **发一条测试消息**，能弹出通知就说明整条链路通了。

## 工作原理

```
iPhone 快捷指令 ──HTTP POST──▶ ntfy.sh（服务端）──长连接推送──▶ 安卓 App ──▶ 通知栏
                                    │
                                    └─ 长连接断开时，App 每 8 秒轮询补齐，短信不会丢
```

- 传输：HTTPS 443，全程加密
- 到达：长连接建立后通常 1 秒内
- 离线：iPhone 发出的消息会在服务端保留一段时间，App 恢复联网后自动补收
- App 侧有常驻前台服务 + 开机自启，锁屏、清后台、重启手机都能继续收

## 常见问题

**Q：状态一直是"正在连接…"**
A：先看首页「诊断信息」里的"最近错误"。如果是网络问题，App 会自动降级成轮询（显示"定时轮询"），仍然能收到，只是延迟几秒。若公司/校园网屏蔽了 ntfy.sh，可在「设置 → 服务器地址」换成其他 ntfy 实例。

**Q：测试消息收到了，但 iPhone 发短信没反应**
A：说明 App 没问题，问题在快捷指令。检查自动化里的条件是否真的触发（把快捷指令手动跑一次，看安卓有没有收到）。

**Q：收到消息但通知栏没声音/不亮屏**
A：通知渠道「短信消息」被降级了。系统设置 → 应用 → 接收苹果短信 → 通知 → 短信消息 → 允许打扰/横幅。

**Q：频道名泄露了会怎样**
A：别人知道频道名就能给你发消息。设置页点「换一个频道」即可，记得同步更新快捷指令里的地址/频道名。
